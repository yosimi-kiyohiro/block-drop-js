# テトリス（JavaScript版）

HTML / CSS / JavaScript（フレームワークなし）で作るテトリス。
プログラミング学習プロジェクト。後で C言語版を作って比較学習する予定。

## 遊び方

`index.html` をブラウザ（Chrome 推奨）で開くだけで遊べます。

### 操作方法（キーボード）

| キー | 動作 |
|---|---|
| ← → | 左右に動く（壁や積みブロックで止まる） |
| ↑ | 回転する（壁際では少し内側にずれて回る＝簡易ウォールキック。Iミノは最大2マス） |
| ↓ | ソフトドロップ（速く落ちる） |
| スペース | ハードドロップ（一気に落ちて即固定される） |
| C | ホールド（1ターンに1回だけ。実装：ステップ3b） |

スマホでは画面下のタッチボタンで操作できます（実装：ステップ3c）。

## 注意

- スマホは**縦持ち専用**です（横持ちは未対応）

## ファイル構成

| ファイル | 役割 |
|---|---|
| index.html | 画面レイアウト・Canvas・タッチボタン |
| style.css | デザイン・スマホ対応レイアウト |
| game.js | ゲームロジック全体 |

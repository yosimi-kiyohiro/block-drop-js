# テトリス（JavaScript版）

HTML / CSS / JavaScript（フレームワークなし）で作るテトリス。
プログラミング学習プロジェクト。後で C言語版を作って比較学習する予定。

## 遊び方

`index.html` をブラウザ（Chrome 推奨）で開くだけで遊べます。

### 操作方法（実装が進んだら追記）

| キー | 動作 |
|---|---|
| ←→ | 左右移動 |
| ↑ | 回転 |
| ↓ | ソフトドロップ |
| スペース | ハードドロップ |
| C | ホールド |

スマホでは画面下のタッチボタンで操作できます。

## 注意

- スマホは**縦持ち専用**です（横持ちは未対応）

## ファイル構成

| ファイル | 役割 |
|---|---|
| index.html | 画面レイアウト・Canvas・タッチボタン |
| style.css | デザイン・スマホ対応レイアウト |
| game.js | ゲームロジック全体 |

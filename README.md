# テトリス（JavaScript版）

HTML / CSS / JavaScript（フレームワークなし）で作るテトリス。
プログラミング学習プロジェクト。後で C言語版を作って比較学習する予定。

## 遊び方

`index.html` をブラウザ（Chrome 推奨）で開き、「▶ スタート」を押すと始まります。

- 横一列をそろえると消えてスコアが入ります（1列100・2列300・3列500・4列800点）
- 10ライン消すごとにレベルが上がり、落下が速くなります
- ブロックが上まで積み上がるとゲームオーバー。「リスタート」で再挑戦できます

### 操作方法（キーボード）

| キー | 動作 |
|---|---|
| ← → | 左右に動く（壁や積みブロックで止まる） |
| ↑ | 回転する（壁際・床の上では少し内側にずれて回る） |
| ↓ | ソフトドロップ（速く落ちる） |
| スペース | ハードドロップ（一気に落ちて即固定される） |
| C | ホールド（取り置き。1ターンに1回だけ） |
| P / Esc | 一時停止 ⇔ 再開 |

### 操作方法（スマホ）

画面下のタッチボタンで操作できます。

| ボタン | 動作 |
|---|---|
| ← → ↓ | 移動（押しっぱなしで連続移動） |
| 回転 | 回転 |
| HD | ハードドロップ |
| HOLD | ホールド |
| ⏸（スコア横） | 一時停止 ⇔ 再開 |

## 注意

- スマホは**縦持ち専用**です（横持ちは未対応）
- 盤面の表示サイズはページ読み込み時に決まります。ウィンドウの大きさを変えたら再読み込み（F5）してください

## ファイル構成

| ファイル | 役割 |
|---|---|
| index.html | 画面レイアウト・Canvas・タッチボタン |

## 学習メモ（このプロジェクトで学んだこと）

- **Canvas の DPR 対応**：CSS の表示サイズと内部解像度を分けて、高解像度画面でも滲まないようにする
- **requestAnimationFrame**：時間管理をゲームループに一本化する（ロック遅延も setTimeout ではなく経過時間の足し算で実現）
- **7-bag 方式**：7種を1セットにして Fisher-Yates でシャッフルすると、同じブロックが偏らない
- **回転は行列の操作**：「回転後の r 行 c 列 ＝ 回転前の (末尾−c) 行 r 列」
- **タッチの暗黙ポインターキャプチャ**：pointerleave に頼らず、座標判定で「ボタンの外に出た」を検知する
